# AGENTS.md



## Repository

Collection of AI coding agent skills. Each skill lives in `<name>/SKILL.md` at the repo root with optional `scripts/` and `references/` directories.

## Creating Skills

Use `/skill-creator` to create new skills in this repo. It provides the proper SKILL.md format with YAML frontmatter and structure.

## Skill Structure

```
<skill-name>/
├── SKILL.md              # Main skill file (YAML frontmatter + content)
├── scripts/              # Optional automation scripts
└── references/           # Optional detailed reference docs
```
